# CityLens 
 A full-stack data visualization tool tracking 8 urban quality parameters (walkability, AQI, cleanliness, aesthetics, public transport) across 25 Indian cities using CPCB, MoHUA, and ISFR open datasets. Features interactive Leaflet ward maps, Chart.js multi-parameter comparisons, real-time AQI gauge, and dark/light theming. Deployed on Vercel.
 Stack: Vanilla JS · Chart.js 4 · Leaflet.js · CSS custom properties · REST APIs.
